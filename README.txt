D2A / Diet2Activity starter website

Files:
- index.html: complete responsive homepage (HTML, CSS and tiny year script are included in one file)

Quick deploy:
1. Create a GitHub repository named diet2activity-website (or another name you prefer).
2. Upload index.html to the repository root and commit the change.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Choose branch "main" and folder "/ (root)", then Save.
6. Wait for deployment and open the URL shown in Settings > Pages. A project site normally uses:
   https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

Edit the CTA link:
Search index.html for https://www.instagram.com/ and replace it with your D2A Instagram profile or waitlist URL.

Note:
GitHub Pages hosts static files. It does not run server-side code or securely store user accounts, food logs, or API keys. Add a backend/service later for sign-in, databases, or AI calorie estimation.
